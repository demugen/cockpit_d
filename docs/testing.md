# Тесты

[← README](../README.md)

Запуск (нужен Node.js не старше 18):

```
node --test test/
```

Форма с каталогом, а не `test/*.test.js`: PowerShell не раскрывает glob.

32 теста проверяют:

- раскладку: клетки скрытых виджетов не удерживают сетку, сохранённый размер не
  теряется при переналадке, видимые карточки не делят одну клетку, первая расстановка
  и возврат скрытого виджета не ниже его минимума;
- громкость: точную запись через `setvol`, шаги по 1 % без `setvol`, отказ в начале
  шага и в середине прохода, отказ `setvol` без обходных шагов, шаг без известного
 начального уровня, отсутствие моста, отставание `getvol` за командой, изменение уровня на
  самом ГУ;
- ответ `carResponse` как единственный источник отказа асинхронного шага и распознавание
  `false` («запрос не принят») отдельно от отказа;
- остановку опроса и прохода шагов при снятии последней карточки и при уходе панели за
  другое приложение;
- мини-карту: общий бюджет из четырёх переподключений и блокировку после него, сброс
  бюджета кнопкой «Подключить снова», отписку при скрытой панели и возврат подписки без
  расхода попыток, три формы кадра, переподключение при молчании ГУ, толерантный флаг
  `naviOn` и тему карты в режиме «Авто».
