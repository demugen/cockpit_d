# Cockpit D

Cockpit D — аддон для JCarTools. Он заменяет рабочий стол головного устройства (ГУ)
на доску с карточками. Внутри HTML, CSS и JavaScript. Сборка и зависимости не нужны.
Панель открывается по `file://`.

Идентификатор аддона: `cockpit_d`. Текущая версия — в `manifest.json`; на ГУ она видна
в «Настройки → О панели» и должна совпадать со сборкой.

Делал под Jaecoo J7 и другие машины семейства Chery. Проверял в браузере. На реальном
ГУ панель пока не запускалась.

## Установка

Загрузите `cockpit_d.zip` в JCarTools как аддон.

В архиве `index.html` и `manifest.json` лежат в корне. Внешняя папка ломает запуск.

## Проверка без машины

Откройте `index.html` в браузере. Если `window.androidApi` нет, заглушка включается сама.
Это демо-режим: музыка, климат, погода, приложения и мини-карта. На машине заглушка
не включается.

## Управление

- Держите карточку 550 мс. Панель войдёт в режим правки.
- Перетащите карточку. Она встанет в выбранные клетки.
- Потяните за ручку в правом нижнем углу. Карточка изменит размер.
- Нажмите «Скрыть». Виджет уйдёт с доски, но запомнит клетку.
- Откройте настройки. Четыре вкладки: «Вид», «Обои», «Виджеты» и «О панели».
- Нажмите «Сбросить всё» два раза. Вернутся заводские настройки.

Свободная клетка остаётся свободной. Если места нет, панель отменяет действие
и пишет причину. Подробности: [docs/guide.md](docs/guide.md).

## Виджеты

По умолчанию на доске семь карточек. «Навигация» и «Окна» включаются
в настройках, раздел «Виджеты».

| id | Что показывает |
| --- | --- |
| `clock` | Время и дата |
| `weather` | Город, температура, состояние |
| `media` | Обложка, трек, громкость |
| `climate` | Две зоны, поток, режимы |
| `cardata` | Выбранные показатели авто, включая свои ключи `getCarData` |
| `seats` | Выбранные функции: подогрев, вентиляция, память |
| `apps` | Плитки приложений |
| `nav` | Мини-карта и манёвр |
| `windows` | Все окна и углы |

Размеры, кнопки и поведение каждого виджета: [docs/widgets.md](docs/widgets.md).

## Сетка

Панель считает сетку от экрана. Целевая клетка — около 200 px. Для горизонтали
и вертикали сетка своя. Раскладка хранится в клетках, а не в пикселях.

Примеры: 1080×1920 — 5×9, 1920×720 — 9×3, 2560×1440 — 12×6.

Все экраны и правила пересборки: [docs/guide.md](docs/guide.md).

## Тесты

Требуется Node.js не старше 18 (тесты используют `node:test`).

```
node --test test/
```

Форма с каталогом, а не `test/*.test.js`: PowerShell не раскрывает glob. 32 теста.
Что они проверяют: [docs/testing.md](docs/testing.md).

## Ограничения

- На реальном ГУ панель не запускалась. Проверка — браузер и синтетические жесты.
- Команды климата, окон и обогревов зависят от прошивки.
- Положение стёкол читает `get_windows_state`; процент для одного окна ГУ не задаёт.
- Мини-карта работает, только если прошивка её отдаёт.
- Нужен WebView с Chrome 88 или новее.
- Обои занимают около 9 МБ в архиве.

Подробности: [docs/limitations.md](docs/limitations.md).
